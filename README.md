#Hairstyle Recommendation System Based on Face Shape#

Project Overview

The Hairstyle Recommendation System is a machine learning project developed to recommend suitable hairstyles based on a person's facial shape. The system uses facial image processing and a trained deep learning model to classify face shapes and provide hairstyle recommendations.

The project aims to help users identify hairstyles that may complement their facial features.

Objectives

- Detect faces from captured images.
- Classify faces into different face-shape categories.
- Recommend hairstyles based on the predicted face shape.
- Provide a simple web interface for users to interact with the system.

Face Shape Categories

The system is designed to classify faces into five categories:

- Heart
- Oblong
- Oval
- Round
- Square

Technologies Used

- Python
- Django
- TensorFlow and Keras
- OpenCV
- Convolutional Neural Networks (CNN)
- Scale-Invariant Feature Transform (SIFT)
- Haar Cascade for face detection
- HTML, CSS and JavaScript

How the System Works

1. The user opens the web application.
2. The user captures a facial image using the webcam.
3. The image is processed using computer vision techniques.
4. The trained machine learning model predicts the face shape.
5. The system uses the predicted category to select suitable hairstyle recommendations.

Key Features

- Webcam-based image capture.
- Facial image processing.
- Machine learning-based face-shape classification.
- Hairstyle recommendations based on predicted face shape.
- Django-based web application.
